## Linux 建议命令

```bash
pip install -e ".[dev]"
sudo apt install -y sysbench fio iputils-ping traceroute
lebench doctor
lebench run --profile vps --intensity standard --yes --output-dir ./reports
```

测速前请配置 `speedtest_targets.yaml`。deep 需 `--confirm-deep`。
