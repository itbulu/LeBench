# LeBench S0 完成报告

日期：2026-11-21

## 已实现命令

| 命令 | 状态 |
|------|------|
| `lebench --version` | 已实现 |
| `lebench doctor` | 已实现（只检查不安装） |

| `lebench run … --modules / --skip` | 已实现 |

## 已实现能力

1. 工程骨架：`pyproject.toml`、包结构、适配器预留位  
2. 统一结果模型 `lebench-internal-v0` 与模块状态枚举  
3. `system` 真实采集（guest 可见信息）  
4. 终端输出 + TXT 报告 + 内部 JSON 快照（含非网站导入声明）  
5. 默认脱敏；`--allow-sensitive` 显式导出  
6. 模块失败隔离、信号处理取消标记、临时目录清理  
7. 单元测试（profiles / result / safety / system / cli）

## 推荐验证命令

```bash
python -m pip install -e ".[dev]"
pytest -q
lebench doctor
lebench run --profile vps --intensity quick --output-dir ./reports
```

## 已知限制

- Windows 上 `system` 字段不完整；**首要验收环境为 Linux VPS**
- ARM64 / 各发行版兼容性：**未宣称已验证**
- CPU/内存/磁盘/网络等模块仅为 stub，`not_run: not_implemented_in_s0`
- 未实现网站 Schema 导出、API 上传、自动发布
